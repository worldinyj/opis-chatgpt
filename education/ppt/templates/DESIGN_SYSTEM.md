# OPIS 집합교육 디자인 시스템 V1.0

16:9 (13⅓ × 7.5 inch). 색상: navy #16364D, teal #287C80, 배경 #F3F6F8. 나눔고딕(NanumGothic) 설치 권장, 글꼴 미포함. 표제 32pt, 기본 본문 21~23pt, 라벨 19pt, 속성 카드 14pt(고밀도 한 장), 각 페이지 초안 상태와 출처 표시. 제목/마무리는 어두운 배경, 나머지는 밝은 배경 및 3행 카드. 토론은 상단 교육용 가상 상황 표시. 속성 요약 2열×3행. 슬라이드 몸체에 텍스트/도형을 네이티브 OOXML 객체로 삽입; 래스터화하지 않음. 참고 이미지·영상은 선택이며 현 MVP에는 없음. 3행 이내, 요약 6그룹 이내의 짧은 문구가 기본. 넘침·글꼴 대체 여부는 실제 렌더링 검사. 출력은 승인 상태를 바꾸지 않는다.

# 선택 샘플 디자인 우선 PPT 제작 표준 V2.0

## 경로
- STANDARD_NATIVE: 기존 12장 OPIS 생성기. 샘플 불필요, 고정 기본 디자인이며 샘플 복제 기능 없음.
- SELECTED_TEMPLATE: 사용자 제공 PPTX/POTX를 원본으로 보존하고 마스터/레이아웃을 재사용하는 별도 경로. ChatGPT 또는 외부 전문 AI도 동일 내용 계약을 사용. 도구가 원본 마스터를 유지할 수 없는 경우 차이 기록 및 사용자 검토.
- EXTERNAL_AI: 선택 샘플과 공통 프롬프트, 보고서, 원장, 승인 상태를 사용자가 승인한 외부 서비스에 전달. 반환된 PPTX를 수입하고 검증한다. 서비스별 지원 범위와 비용은 실제 실행 전 확인. 현재 외부 전송 없음.

## 템플릿 입수와 분석
원본 파일명·SHA-256·슬라이드 크기·페이지 수·사용권·등록 경로를 기록. 샘플에 남은 원래 내용/기관명/로고는 권한과 필요성을 검토하고 미승인 재배포 금지. 실제 슬라이드 렌더링을 확인하고 표지, 본문, 목차, 섹션, 표/카드, 다이어그램, 마무리별 후보 샘플 장표/마스터/레이아웃 ID를 추출. 테마색, 실제 적용색, 글꼴(동아시아 포함), 크기, 여백/정렬, 도형·선·표 스타일, 바닥글/페이지 번호를 기록. 글꼴/로고/이미지 사용권 별도 확인. 원본 보존, 새 파일에 적용.

## 매핑 및 제작
내용 blueprint → 샘플 레이아웃 매핑표 → 복제/수정 또는 전문 AI 제작 → 실제 렌더링 → 내용·디자인·편집성 검토 → 승인. 매핑표에는 장표 ID, 샘플 페이지, 마스터/레이아웃 ID, 재사용 방식, 차이 및 이유를 기록. 새 테마는 임의 선택하지 않는다. 원칙·속성 카드 한 장은 필수; 12~16장이 기본. 글자 크기·여백 부족 시 본문 축약/노트 이동, 정보 삭제 금지. 모든 발표자 노트에 근거와 설명. 승인 전 샘플과 결과의 실제 렌더링 비교, 글꼴 대체·색상·마스터·표·다이어그램·페이지별 차이를 확인한다.

## 검수와 게이트
내용: F/L 연결, 표준 코드·명칭 일치, 원인 분류·단위·기간·미확정 표현·긍정 대응, 토론 3/2, 실천 확인. 디자인: 샘플의 표지/레이아웃/글꼴/팔레트/도형 일치 여부와 차이 기록. 기술: PPTX 열기, 노트, 편집 가능 요소, 오버플로·가독성, PDF 실제 렌더. 기존 verify_pptx.py는 고정 디자인 무미디어 파일의 기본 검사이며 이미지 포함 외부 PPT에 그대로 적용할 수 없다. 외부 결과 검사기는 별도 구현 대상. 승인: 내용 검토, 디자인 검토, 실제 매체 QC, 교육 배포 각각 별도. 누락된 샘플·권한·실제 도구 미지원은 차단 또는 기록; 임의로 PASS 처리 금지.

## 현재 상태
새로 선택한 샘플 PPT/POTX 미수신. 기존 R3의 실측은 16:9, 12장, NanumGothic, 배경 #16364D/#F3F6F8, 강조 #287C80, 흰 카드, 32pt 표제 등 기존 고정 디자인을 확인한 것일 뿐 선택 샘플 디자인 적용의 근거가 아니다. 샘플 매핑·외부 도구 실행·새 PPTX 생성 미수행. 다음 단계에서 실제 샘플 수신 후 선택형 적용을 실증.

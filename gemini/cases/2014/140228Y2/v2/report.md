## 1. 사건 개요 및 분석 범위

## 4. 주요 선정·판단보류·긍정 요소 상세 분석

### 4.1 직접기여 (`D`, 13개 → 선정)
- **QA1 (원자력의 특수성)**: 원자로정지를 직접 유발할 수 있는 지진 원자로 자동정지 설비(ASTS)의 가압 M-G set 연결 후 최초 주기기능시험(주기-6762E)을 중요시험으로 분류하지 않고 작업전회의에서 원자로정지 유발 가능성도 검토하지 않은 점은 안전 특수성 인식 부족을 보여준다. (GEMINI-F02, GEMINI-F04)
- **QA2 (불확실성 확인)**: M-G set 연결('13.11) 후 우회/차단 스위치 Open 상태에서의 주기 기능시험이 최초였음에도 회로 오류·정지 유발 불확실성을 사전 확인하지 않았고, 채널 1 시험 중 'ASTS Ch 1 Trip' 경보가 Reset으로 소멸하자 차단기 개방 여부를 확인하지 않은 채 채널 2 시험을 진행했다. (GEMINI-F01, GEMINI-F02, GEMINI-F04, GEMINI-F05)
- **QA3 (가정상황 확인)**: 우회/차단 스위치를 Open하면 출력차단기가 개방되지 않을 것이라는 가정, 인수·교정시험 통과로 회로가 정상일 것이라는 가정, 그리고 경보절차서대로 'Rod Drive M-G set Trouble' 경보가 발생할 것이라는 가정에 도전·검증하지 않아 채널 1 개방을 놓친 채 원자로정지를 초래했다. (GEMINI-F02, GEMINI-F04, GEMINI-F05)
- **CO1 (업무 소통)**: 타 원전(고리 4호기 등) 시공 중 확인·수정된 ASTS (-) 전원 공통연결 오류 내용이 공급사로부터 한빛 1발전소에 통보되지 않았고, 시험 당일 작업전회의에서도 '시험 중 원자로정지 유발 가능성' 등 중요 안전사항이 전달·검토되지 않았다. (GEMINI-F03, GEMINI-F04)
- **LA5 (변화 관리)**: 한수원 설계변경관리절차서(표준정비-9044A)에 초기 설계변경서 승인(rev.0, '11.8.1) 이후 타 원전(고리 4·1·2호기, 표준형 원전)에서 발생한 추가 개정·현장수정 사항을 기시공 호기(한빛 1·2호기)에 전파·반영하는 변화관리 절차가 미비해 회로오류가 방치되었다. (GEMINI-F03, GEMINI-F08)
- **DM1 (일관적 프로세스)**: 초기 설계변경 승인(rev.0) 이후 추가 변경사항에 대한 재검증·타 원전 전파 의사결정 프로세스(설비기술검증위원회 등)가 부재했고, 원자로정지 유발 가능 설비인 ASTS 기능시험을 중요시험으로 분류하는 의사결정 프로세스도 작동하지 않았다. (GEMINI-F03, GEMINI-F04, GEMINI-F08)
- **DM2 (보수적 성향)**: 가압 M-G set 연결 후 최초로 수행되는 ASTS Open 상태 주기기능시험을 보수적으로 중요시험으로 분류하지 않았고, 채널 1 시험 중 'ASTS Ch 1 Trip' 경보가 발생했을 때 M-G set #1 출력차단기 상태를 확인하지 않은 채 채널 2 시험을 진행해 원자로정지·안전주입을 초래했다. (GEMINI-F01, GEMINI-F02, GEMINI-F04, GEMINI-F05)
- **CL1 (운전 경험)**: 한빛 2호기 설치('11.9.30) 직후 고리 4호기('11.10월)와 표준형 원전 시공 중 동일 ASTS 설비의 (-) 전원 공통연결 오류가 발견·수정되어 고리 1·2호기까지 반영되었음에도, 이 타 원전 경험이 기시공된 한빛 1·2호기로 전혀 환류되지 못해 사건을 초래했다. (GEMINI-F03)

- **PI2 (문제 평가)**: ASTS 기능시험이 원자로정지를 유발할 수 있는 위험을 사전 평가해 중요시험으로 분류하지 못했고, 고출력 운전 중 ASTS 작동으로 제어봉 낙하 시 터빈 미정지에 따른 주증기관 저-압력 안전주입 발생 가능성에 대한 설계 타당성 평가도 사전에 미흡했다. (GEMINI-F04, GEMINI-F06)
- **WP1 (작업 관리)**: KINS가 사건 요약과 결론에서 명시한 바와 같이, 원자로정지 유발 설비의 기능시험을 중요시험으로 분류하지 않고 작업전회의에서 정지 유발 가능성을 미검토했으며, 가압 M-G set 연결 후 Open 상태 기능시험 오류를 사전 검증하지 못한 시험관리 미흡이 직접 기여했다. (GEMINI-F02, GEMINI-F04)

- **WP3 (문서화)**: 설계변경관리절차서(표준정비-9044A)에 추가 개정 타 원전 전파 절차가 누락되었고, ASTS 기능시험절차서(주기-6762E)에 M-G set 출력차단기 개방 여부 확인 단계가 없었으며, 경보절차서('Rod Drive M-G set Trouble' 발생)와 경보논리도(미발생) 간 불일치가 운전원의 오인을 초래했다. (GEMINI-F03, GEMINI-F04, GEMINI-F05)

### 4.2 간접기여 (`I`, 5개 → 선정)

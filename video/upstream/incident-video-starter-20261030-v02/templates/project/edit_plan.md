# 편집 결정 기록

- 목표 총 길이: production.json timing 참조
- 인트로/아웃트로: cards 참조, 생성 이미지에는 글자를 넣지 않고 편집에서 제목·교훈 삽입
- 전환: overlap_seconds는 클립끼리 실제로 겹치는 길이. 내부 페이드만 사용하면 0
- 본편 자막: 나레이션과 동기화, 480p 휴대전화 화면에서 가독성 확인
- 나레이션: 클립별 음성 파일, 실제 길이 기록. 구간을 넘으면 문장/클립 수 조정
- BGM: 음성 가독성을 유지하는 수준, 사용권 확인
- 영상 원본 오디오: 음소거 후 별도 음성/BGM 합성
- 최종 확인: 실제 화면비·해상도·음성 겹침·익명화·사실 일치·총 길이
- 최종본 파일 / 실제 길이 / 확인자 / 날짜: 미완료

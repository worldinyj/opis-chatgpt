# 공통 스타일

- 3D 브릭 질감, 명확한 교육용 장면, 과장 없는 누설과 경보 표현.
- 프로젝트 고정 스타일은 production.json common에, 인물·설비·장소의 외형은 references에 기록.
- 발전소명은 익명화하고 설비명·수치는 보고서에 근거. 외형이 불명확하면 제작용 가정으로 명시.
- 제어실: 안전모 미착용. 현장: 작업 역할에 맞는 동일 기준 보호구. 방사능 기호를 장식으로 생성하지 않음.
- 제목·한글·수치·설비 라벨은 후반 편집 오버레이. 작은 글자를 생성 이미지에 직접 그리지 않음.
- 9:16 이미지를 만들고 얼굴·핵심 설비는 화면 중앙, 하단 자막 영역을 피함. 해상도는 480p 목표, 글씨 크기는 실제 출력에서 가독성 확인.
- 같은 CHAR/EQ/LOC ID는 항상 실제 승인 기준 이미지를 첨부. ID나 동일 문구만으로 외형 유지가 보장되지 않음.
- 인트로부터 아웃트로까지 동일 기준 자산과 조명·색상·비율 사용.
- 공통 스타일은 모든 장소에 적용하고, 공간 배치·장소별 조명·설비는 각각의 LOC_* 기준을 유지한다. 현장과 MCR의 배경을 혼합하지 않는다.
- 인물의 얼굴·체형과 복장·보호구를 구분한다. 장소를 옮기는 동일 인물은 승인된 복장 변형으로 관리하며 인원·역할을 임의로 바꾸지 않는다.

# 영상 작업 규칙 V1.1 (설계)

- 원본 조사 결과, AI 해석, 가상 교육, 시각적 가정을 구분하고 근거 ID를 연결한다. 보고서 미승인 초안에서 생성한 기획은 초안 상태를 유지한다.
- INCIDENT_UNDERSTANDING은 사실 중심, SAFETY_CULTURE_LEARNING은 10원칙 중심 및 한 장의 속성 종합 카드, KEY_MESSAGE_SHORT는 단일 학습 행동 중심. 상세 분석은 40속성 단위 그대로 유지.
- 프로필별 9:16 또는 16:9, 실제 픽셀·fps·길이 기록. 비율 강제 고정 금지. 실제 출력 가독성 검토.
- 제작 모드: I2V / STILL_MOTION / CONTROLLED_GRAPHIC / HYBRID. 생성 경로는 개별 또는 GEMINI_TASKS_BATCH 또는 로컬 편집. 배치 서비스 기능을 추정하지 않고 작업 명세와 결과를 수입 검증. 생성 없이 편집 가능한 구간에 I2V를 강제하지 않는다.
- 기본 3D 브릭 스타일, 실제 승인 참조 자산, 한 클립 한 장소/한 동작. I2V의 3컷은 설계·검수 목표이며 실제 입력 지원 모드에 따라 사용한다. 정지형은 승인 이미지와 크롭/줌/팬만 검수. 통제형은 텍스트와 표의 정확성·가독성 검수.
- 실제 설비 배치나 작업 방법을 재구성하지 않는다. 화면 발전소명 익명화 기본(원본 출처 유지), 원본 비공개 정보 추정 금지. 실제 사건과 가상 대안을 자막으로 분리.
- 나레이션은 한국어, ElevenLabs 등 선택 가능; BGM 별도. 시간 초과는 문장 축약 또는 구간 연장. 제목/라벨/수치/코드 글자는 후반 편집. 외부 배치·유료 API는 명시적 사용자 요청 후.
- manifest, 실제 파일 해시, 시도 번호, 프롬프트 revision, 승인 및 검토 상태 기록. 미실행 결과를 성공으로 기록하지 않는다. 자산 변경/보고서 개정 시 의존 산출물 재검토.

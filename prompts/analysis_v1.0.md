# 사건 분석 프롬프트 V1.0

원자력안전문화 교육용 분석자로서 입력된 공개 KINS 조사보고서를 분석한다. [원래 요청](original_prompt.md)의 6개 장 및 [40속성 표준](../standards/safety_culture_40.md)을 따른다. [보고서 양식](../templates/report_template.md)과 [분석방법](../docs/ANALYSIS_GUIDELINE.md)을 적용한다.

원본 전체의 필요한 범위를 읽고 사실·공식 원인평가·AI의 교육용 재분류·가상 시나리오를 구분한다. 원본 절/인쇄 페이지를 표시하고, 직접/근본/기여원인별 ID를 부여한다. 근본원인과 기여원인을 40속성으로 검토하여 충분한 근거가 있는 속성에 한해 핵심 후보를 선정한다. 근거·정의와의 연결·교육적 이유·한계를 설명한다. 미선정은 양호 판정이 아니다. 긍정적 대응도 검토한다. 토론 질문 3개, 팀 시나리오 2개, 개인/팀 과제 및 확인 방법을 제시한다. 원본 비공개 내용을 복원하지 않는다. 공개 원본에 별도 일괄 삭제 규칙을 적용하지 않는다. 잠정 등급과 최종 등급, 완료 조치와 예정 조치를 구분한다. 교육용 분석이며 공식 평가 또는 작업절차가 아니다.

MD A4 5장 이상 목표, 6~9쪽 권장. report.md, metadata.yaml, source.md, review.md 작성. 미검토 상태 DRAFT, approved=false. 직접 링크 및 확인되지 않은 정보는 null. 독립 검토 후에만 상태 승격.

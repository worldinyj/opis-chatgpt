# 데이터 관리 V1.0

공개 OPIS 조사보고서를 원문 출처로 사용한다. 목록 URL, 상세 팝업 식별자, 공식 보고서 번호, 날짜, 페이지 수, 원문 파일 식별정보와 판본을 기록한다. 직접 PDF URL이 확인되지 않으면 null로 유지한다. 다운로드·재배포 조건은 별도로 확인하고 그 전에는 PDF를 GitHub에 복제하지 않는다.

2026-11-24 결정: 공개 조사보고서의 기술 세부정보에 대한 별도의 포괄적 삭제 규칙을 두지 않는다. 원본에서 가린 정보는 복원하지 않고 필요한 맥락만 원문에 충실하게 기술한다. 개인 비난과 내부 미공개 자료의 추정은 금지한다.

공식 조사내용, AI 초안, 독립검토, 전문가 승인 여부를 표시한다. 원본 수정 발견 시 기존 버전 보존 후 재분석. 코드 정의 개정 시 이전 표준 버전 보존. 출현빈도는 표본·분모·버전·검토 상태를 명시한다.

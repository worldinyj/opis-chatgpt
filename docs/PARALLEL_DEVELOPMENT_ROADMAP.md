# 독립 병행 개발 로드맵 V1

38건 기준선은 고정하고 다른 모델의 실제 분석결과를 읽지 않는 작업을 우선한다. 모든 개발 파일은 cases/, gemini/, claude/ 및 공통 기준 동결 범위 밖에 작성한다. 기존 산출물 덮어쓰기 금지. 가상 테스트는 명확히 분리하고 실데이터로 집계하지 않는다.

| 단계 | 작업 | 완료 기준 | 상태 |
|---|---|---|---|
| 4-A-01 | ChatGPT 기준선 | pinned commit, manifest, CSV, 검증기, 가상 테스트 | 개발 완료 / 실 clone 실행 대기 |
| 4-A-02 | 외부 AI 산출물 검증기 | ZIP 경로 안전성, 40속성·schema·ID·CSV·근거·판본 검증, 가상 실패 테스트 | NEXT |
| 4-A-03 | Excel 업데이트 | 모델별 열만 값 입력, 기존 수식/판정 보호, 변경 이력, 복사본 저장 | 대기 |
| 4-A-04 | SQLite DB | 독립 모델별 레코드 및 원본/속성/전문가/교육 관계, 테스트 | 대기 |
| 4-A-05 | 통계 | 3AI 일치도/불일치/검토량, 결측/보류 분리, 가상 데이터 검증 | 대기 |
| 4-A-06 | 교육 디자인 | 기존 판단 변경 없이 표준 템플릿과 기술 QC | 대기 |
| 4-A-07 | RAG 설계 | 원문/사실/판단/출처의 분리 및 권한, 평가셋 | 대기 |
| 4-A-08 | Django 웹앱 | 검색·조회·비교·판정 화면, 합성 테스트 | 대기 |

실제 외부 결과 반영은 독립 분석 완료 후 별도 통합 검증 단계. 3AI 선정 합의는 프로젝트 내부 확정 기준이며 공식 규제 평가 또는 배포 승인 아님. 전문가 검토·교육 최종 개정은 별도. can_ship=false.

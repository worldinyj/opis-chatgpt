# 사건 처리 중단·재개 규약 v1.0

공개 조사보고서는 안전문화 교육 목적의 근거로 사용한다. 원문 사실과 교육 해석, 확인되지 않은 정보 및 전문가 판정을 구분한다. 공개 판본의 비공개 부분은 복원하지 않는다.

1. 매 세션 시작 시 main HEAD, intake_queue, REVIEW_STATE 및 VALIDATION을 읽어 실제 마지막 완료 단계를 확인한다.
2. 원본 확인→분석/원장/토론→영상 설계→PPT 생성→실제 렌더→최종 재조회 단위로 커밋한다. 호출 제한을 피하기 위해 영상과 PPT는 별도 작업으로 나눈다. 각 커밋 후 HEAD를 확인한다.
3. 렌더는 저장소 blob과 로컬 파일의 해시 일치 및 실제 렌더 결과 확인 후에만 PASS로 기록한다. 실패·중단 시 PENDING 상태를 유지하고 다음 호출에서 해당 단계부터 재개한다.
4. 최종 단계만 대기열을 다음 사건으로 이동한다. 전문가 판정·실제 영상 생성은 별도 승인으로 남긴다. 이미 커밋된 파일은 불필요하게 재생성하지 않는다.
5. 실행 환경 중단 자체를 보장하여 방지할 수는 없다. 확인된 장애와 남은 작업을 사용자 및 저장소에 명시한다.

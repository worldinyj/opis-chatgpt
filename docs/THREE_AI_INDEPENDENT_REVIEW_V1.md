# Phase 4-A — 3AI 독립 분석 및 Excel 통합 운영 V1

## 결정 기준
현재 38건 × 40속성 1520행, ChatGPT D/I 253개, 추가 검토 717개. 기존 Phase 3-E 및 cases/ 원본 AI 산출물은 보존한다. 3AI 모두 '선정'이고 독립성·원문 근거·판본·입력 무결성 검사 통과 시 프로젝트 내부 합의 확정; 2개 이하(0 포함)는 전문가 판정 대상. 0표는 필요 시 전문가 일괄 확인 가능하되 자동 기각하지 않는다. 판단보류는 응답 완료이나 선정표가 아니다. 미검토/누락은 응답 완료 아님. 세 모델 합의는 공식 안전문화 판정·교육 배포 승인이 아니다. can_ship=false 유지.

## 폴더와 독립 실행
- cases/<연도>/<event_id>/ : 기존 ChatGPT 산출물(원본·이력 보존).
- gemini/cases/<연도>/<event_id>/v1/ : Gemini 독립 결과.
- claude/cases/<연도>/<event_id>/v1/ : Claude 독립 결과.
- 각 실행에서 [공통 프롬프트](../prompts/independent_ai_review_v1.0.md), [표준 JSON](../standards/safety_culture_40.json), [출력 스키마](../standards/independent_ai_review_v1.schema.json), 동일 판본 PDF, 해당 사건 중립 메타데이터/독립검토양식 40행만 제공한다. 전체 repo/통합 엑셀을 외부 모델에 제공하지 않는다. 동일 repo에 폴더를 분리해도 접근 제어가 아니므로 독립 실행은 별도 깨끗한 작업 디렉토리 또는 새 세션에서 수행한 뒤 사람이 제출 파일을 적재하는 것을 기본으로 한다. 다른 AI 결과의 존재만으로 분석을 중단할 필요는 없으나 읽은 경우 독립 검토로 집계하지 않는다.
- Gemini·Claude 실행 각각 38건, 한 번에 한 사건. 동일 PDF 바이너리의 SHA-256 대조가 가능한 환경에서 수행. 원본 파일은 재배포하지 않는다. 입력 판독 불가 시 대기 상태 유지. 모델별 결과는 v1 잠금, 수정 시 v2 등 별도 보존. 실제 모델 버전 및 입력 판본 기록.
- report.md, review.json, excel_import.csv 세 파일 필수. JSON은 스키마 검증과 별도로 40개 코드 집합, 유일 키, 모델별 ID 접두사·참조, 정확한 표준 명칭, 판본, 페이지 범위, 출처 일치, 보고서/CSV 일치 검증 필요. 이 문서는 실행 규칙이며 자동 검증기 구현/실행은 후속.
- ChatGPT 기존 결과가 원문 전체 재판독을 통해 동일 V1 규칙으로 생성된 새 결과는 아니다. 현재의 Phase 3 후보를 기준으로 재사용하되 독립성/판본/근거 비교에 한계가 있으면 합의 자동 확정 전 재검토한다.

## Excel 반영 계약 (기존 OPIS_38건_3AI_교차검토_전문가판정_V1.xlsx)
통합검토 시트: 3행 헤더, 4~1523행 데이터. A 검토키(ROOT-xxx-코드), B 관리번호, C 사건 ID, H 속성코드. 검토키로 정확히 매칭, 행 순서에 의존 금지. Gemini CSV review_result/rationale/source → P/Q/R, Claude → S/T/U. O ChatGPT 검토결과, V/W/X 및 AC 최종 결과 수식, Y:AB 전문가 입력은 보존. 독립검토양식 K/L/M에 동일 세 필드를 입력할 수 있다. 외부 CSV는 formula injection 방지(수식 시작 문자 셀은 텍스트 처리), 40개 완전성, 후보별 근거 및 문서 동일성 확인 후 값만 적재. 원본 CSV와 JSON 및 보고서 보존. Excel의 3표 수식은 입력 품질과 독립성을 자동 보증하지 않으므로 근거/판본 검사 실패 시 적재하지 않는다. 전문가 선정/미선정에는 사유·검토자·검토일 필수.

## 실행 순서
1. 첫 사건 ROOT-038 또는 ROOT-005를 두 모델에 동일 입력으로 독립 실행, 보고서 및 40행 반환.
2. 통합 담당자가 형식 및 출처를 검증하고 두 결과를 저장, 결과 잠금 이후 Excel에 반영.
3. 파일럿에서 코드 누락·근거 부실·모델 편향을 점검한 뒤 37건 확대. 기준 변경 시 기록하고 이미 분석한 사례 재검토.
4. 합의 확정/전문가 판정 이후 별도 버전의 최종 데이터셋을 생성. 기존 reports/media 및 표준은 자동 변경 금지.

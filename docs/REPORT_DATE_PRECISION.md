# 보고서 발행일 정밀도 계약

2026-11-25 / PILOT-26: 원본 KINS 2006-16호 표지에는 2006.11.까지만 기재되어 있어 report_date=2006-11을 보존한다. 기존 일자 형식 YYYY-MM-DD와 월 형식 YYYY-MM을 fact_ledger, discussion_action, production의 source.report_date에서 모두 허용하도록 정규식의 일 부분을 선택적으로 변경했다. 스키마 버전 2.0의 기존 데이터는 유효하며 다른 필드는 변경하지 않았다. 발행 일자가 확인되지 않은 경우 01일이나 말일을 가정하지 않는다. index 및 metadata의 발행일 역시 원문 정밀도를 유지한다. 기존 등록 25개 발행일의 형식 및 각 3개 변경 패턴의 양성 2·음성 5 예제를 검증했다. 전체 애플리케이션 날짜 소비부 회귀검증은 미수행이며, 후속 작업에서 날짜 파싱은 월 정밀도를 고려해야 한다. 이전 사건의 검증 기록은 당시 스키마 blob 기준으로 유지한다.

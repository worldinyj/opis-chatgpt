# 프로젝트 계획 V1.1

## 목적
공개 OPIS/KINS 원전 사건 조사보고서를 한수원 안전문화 10원칙·40속성으로 재해석해 A4 5장 이상 교육용 MD 사례를 축적한다. 원본 조사결과와 AI 분석을 구분한다.

## 구조
- docs: 운영기준, 품질, 데이터, 향후 개발
- standards: 원칙·속성 정의 MD/JSON
- prompts: 사용자 원본, 분석·검증 버전
- templates: 보고서/메타데이터/검토 양식
- cases/YYYY/ID: 사건별 report.md, metadata.yaml, source.md, review.md
- index: Markdown 목록 및 CSV/JSON
- schemas/scripts/tests: 데이터 누적 후 자동화

## 단계와 완료 기준
1. 기반 구축: 표준 및 양식, 원본 식별 및 상태 체계 등록.
2. 시범 사건 1건: 보고서 6장 구성, 근거 추적, 자체검토 기록 및 전문가 검토 대기.
3. 5~10건 시범: 서로 다른 원인 유형을 선정, 판정 일관성 평가, 프롬프트 개정.
4. 수집 확대: 사건 중복/개정판 관리, 원본 범위 기록, 일관된 작성.
5. 활용 확장: [향후 개발](FUTURE_DEVELOPMENT.md).

## 멀티미디어 확장
사건 이해 영상, 안전문화 교육영상, 핵심 메시지 숏폼, 편집 가능한 집합교육 PPT, 토론·실천자료를 동일 사건 ID 및 근거 원장으로 연계한다. 공통 제작 프레임워크와 첫 사례 기획을 보고서 독립검토 전에 구축하되 최종 승인·대량 제작은 검토 이후로 분리한다. 분석 40속성, 교육 10원칙 중심, 별도 속성 요약 페이지. 화면비 9:16/16:9 선택, 개별 생성 및 Gemini Tasks 배치와 통제형 편집 지원. [멀티미디어 계획](MULTIMEDIA_PRODUCTION_PLAN.md), [개발 우선순위](IMPLEMENTATION_ROADMAP.md) 참조.

## 성공 기준
근거 추적 가능, 명확한 원인 분류, 교육 가능성, 검토 이력, 속성 코드 유효성. 분석 건수 자체를 품질지표로 삼지 않는다.

## 결정사항
2026-11-24 사용자 지시: 공개 조사보고서에 대한 별도의 포괄적인 기술 세부내용 삭제 규칙은 적용하지 않는다. 원본의 비공개 정보는 그대로 존중한다. 원본 PDF의 재배포 조건은 확인 전 링크만 기록한다.

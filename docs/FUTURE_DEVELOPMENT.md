# 향후 개발 로드맵 V1.0 (미구현)

## A. 사건 검색 및 유사사례 탐색
연도, 호기, 사건분류, 운전상태, 원인유형, 속성 코드로 필터하고 보고서 원문 근거에 연결한다. 검색 결과는 검토 상태를 표시한다. 사건명 및 핵심 교육 교훈의 검색과 유사사건 비교를 지원한다. 초기에는 정적 Markdown 인덱스와 CSV/JSON, 이후 웹 UI.

## B. 안전문화 10원칙·40속성 경향분석
발생연도별/호기별/사건분류별 사건×속성 빈도와 비율을 제공한다. 분모는 해당 조건의 분석·승인 사건 수. 한 사건에 여러 속성이 가능하므로 비율 합계는 100%를 초과할 수 있다. 미분류와 미확인 구분, 원인별 다중 매핑, 동시출현, 버전별 민감도 비교. 분석 결과는 운전경험 학습 주제 분포이며 발전소 안전문화 등급이나 위험도 순위가 아니다. 희소 표본은 불확실성을 표시한다.

## C. 주제별 교육 사례집
속성별 대표 사례, 비교 가능한 사례, 공통 교훈, 토론 질문, 진행자 가이드와 학습 확인 문항을 묶는다. 각 인용은 사건 ID와 근거 절에 연결한다. 검토된 사건만 확정 사례집에 포함.

## D. 직무별 교육자료
운전/정비/엔지니어링/관리자 등 직무별 역할과 실제 의사결정 상황을 반영한 토론형 자료. 한 사건에서 부서 간 연결과 공동 개선 과제를 제시하고 직무별 학습 목표·소요시간·진행방법·평가 질문을 구성한다.

## E. RAG 및 K-NSCA 연계
승인된 보고서를 장·원인·근거 단위로 청킹하고 사건 ID, 원문 위치, 속성 버전 및 검토 상태를 메타데이터로 보존한다. 원본과 AI 해석을 별도 컬렉션 또는 타입으로 구별. 동일 사건은 학습/평가 데이터 분할 시 분리 누출을 방지한다. 정답 근거 추적성, 검색 recall, 속성 판정 정밀도와 재현율, 근거 없는 답변 비율을 평가한다. 추론 결과는 전문가 검토 대상으로만 활용한다. K-NSCA 연결은 데이터 계약 및 권한 검토 후 시행.

## F. 자동화 및 품질
스키마 검증, 인덱스 생성, 중복 원본 식별, 버전 변경 감지, 근거 누락 검사, 문서 출력. 목록 수집은 OPIS 이용조건과 접근 정책 확인 후 설계. 원본 접근 실패·파싱 실패는 기록하고 재시도 제한. 모든 분석은 상태 및 원본 판본과 연결.

## 우선순위
1. 5~10개 시범 및 판정 보정 → 2. 자동 목록/검증 → 3. 검색·경향분석 → 4. 주제·직무별 사례집 → 5. RAG/시스템 연계. 단계별 독립 검증 및 승인. 현재 기능 구현은 범위 밖이다.

## 운영 규칙

1. 원본 파일 식별 및 전체 PDF 확인, 해시/페이지/발생일 확인
2. 기존 사건 ID·제목·판본 중복 검사
3. 6장 보고서, 사실/학습 원장, 40속성 후보 및 검토 쟁점
4. 영상 120초 2종 및 숏폼 30초 제작 설계
5. 12~16장 편집형 PPTX 및 노트, 실제 렌더 및 기술 검사
6. 토론/실천자료, 전문가 검토 패키지, index 갱신
7. GitHub 커밋 및 readback, 작업 대기열 상태 갱신

표 기준 작업 순서와 원본 사건발생일·발견일·보고일·발행일 분리. 원본이 없거나 판본 불명확하면 해당 항목을 BLOCKED로 기록하고 다음 진행 여부를 명시한다. 날짜만으로 사건을 병합하지 않으며, 같은 사건의 보조자료는 동일 사건 폴더 내 출처 기록으로 관리한다. 기존 index/events.json은 분석 초안 작성 및 확인 후에만 갱신한다. 전문가 미진속성 검토 별도, 공식 승인 전 can_ship=false. 유료 생성 및 외부 AI 제출 금지. 실제 렌더 실패 시 미검증 상태를 유지한다.

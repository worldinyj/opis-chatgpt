## 수행 기준

1. 원본 파일 식별 및 전체 PDF 확인, 해시/페이지/발생일 확인
2. 기존 사건 ID·제목·판본 중복 검사
3. 6장 보고서, 사실/학습 원장, 40속성 후보 및 검토 쟁점
4. 영상 120초 2종 및 숏폼 30초 제작 설계
5. 12~16장 편집형 PPTX 및 노트, 실제 렌더 및 기술 검사
6. 토론/실천자료, 전문가 검토 패키지, index 갱신
7. GitHub 커밋 및 readback, 작업 대기열 상태 갱신

한 번에 PDF 하나씩 처리. 같은 날짜의 판본은 크기가 큰 파일을 먼저 읽되 우선순위가 완전성의 증거는 아니다. 동일 사건으로 확인되면 출처를 추가하고 신규 사건을 중복 생성하지 않는다. 파일명 날짜와 발생일·발견일·보고일·발행일을 구분한다. 기존 인덱스는 분석 초안 등록 시에만 갱신한다. 실제 검증 실패는 미완료로 명시한다. 전문가 미진속성 검토 별도; 공식 배포 미승인, 유료 생성 및 외부 AI 제출 금지. 루트 외 자료는 추가하지 않는다.

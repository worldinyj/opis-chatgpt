# Phase 3-C 속성 역할 정규화 v1.0

40개 표준 속성마다 단 하나의 통계 역할을 할당한다. D 직접검토, I 간접검토, H 교육가설, P 긍정학습, 추가검토 대기, 기존 미선정(근거부족·낮은 관련성의 잔여집합)이다. 마지막 두 역할은 개별 근거 재판정이 아니다. 기존 학습 원장의 core/additional 및 표준 전체 집합을 사용한다. 기존 metadata.yaml의 추가/미선정 배열과 별도 대조는 후속 검증으로 남긴다.

D/I는 미진 확정이 아닌 검토 후보. H/P는 미진 후보 집계 제외. 모든 원래 후보 및 학습 태그와 기존 리뷰 근거를 보존한다. P는 명시적 핵심 긍정학습만 나타내며 모든 긍정 근거의 총계가 아니다. 혼재하는 반증은 향후 별도 증거 레코드로 보완한다. 기존 events.json, metadata.yaml, 교육자료, 원본을 수정하지 않는다.

정규화 코드 normalize_attribute_roles.mjs는 사실 ID, 학습 ID, 입력 blob, 집합 분할, 승인 보호를 검사하고 구조적 오류와 의미 검토 경고를 구별한다. F ID 존재는 의미 타당성이나 원본 페이지 정확성을 증명하지 않는다. 자동으로 참조 또는 속성 판정을 변경하지 않는다. 결과는 사건별 review_package/ATTRIBUTE_ROLES_V1.json 및 별도 전체 인덱스로 관리한다. 원본 재판독과 전문가 검토, 전체 기술 출력검증은 별도 진행한다.

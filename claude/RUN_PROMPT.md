# Claude 실행 지시문 V1

다음 텍스트와 공통 프롬프트 본문, 안전문화 표준 JSON, 출력 스키마 및 해당 사건 원본 PDF/독립검토양식 40행을 새 독립 세션에 제공한다. repo 전체 또는 다른 모델 결과는 제공하지 않는다.

---

ANALYZER=CLAUDE
QUEUE_ID=<관리번호>
EVENT_ID=<사건 ID>

첨부한 원본 KINS PDF와 한수원 10원칙·40속성 표준만으로 이 사건을 독립적으로 분석하라. 첨부된 OPIS 독립 안전문화 분석 공통 프롬프트 V1.0 및 JSON 스키마의 모든 규칙을 준수하라. 이전 ChatGPT 분석결과나 다른 AI 결과를 읽거나 참고하지 말라. 사건별 한국어 6장 구성의 report.md, 40속성 전체 review.json, 40행 excel_import.csv를 작성하고 각 파일을 제공하라. 입력이 불충분하면 임의 보완하지 말고 STOP_INPUT_REQUIRED로 종료하라. 실제 저장할 수 있는 경우에만 claude/cases/<발생연도>/<EVENT_ID>/v1/에 세 파일을 저장하라. 그 외에는 파일을 반환하여 통합 담당자가 등록하도록 한다. 다른 파일은 수정하지 않는다. 모델 버전 및 원본 판독 한계는 실제 확인한 것만 기록하라. 승인 또는 교육 배포는 하지 않는다.

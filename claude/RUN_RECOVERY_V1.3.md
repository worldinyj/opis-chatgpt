# Claude 독립 분석 실행 보완 지침 V1.3

- 분석자 CLAUDE 고정. 공통 분석 V1.0, 표준 V1.0, 출력 schema, 중립 큐, master workflow V1.1은 변경하지 않는다.
- 사용자 제공 원본 PDF 폴더의 MIME/파일명/크기를 먼저 확인한다. PDF가 아닌 영상·전사문·다른 AI 자료는 열지 않는다. 이미 노출됐다면 해당 사건을 독립 합의 집계에서 보류하고, 기존 산출물을 보존한다. 새로운 세션에서 원본과 공통 입력만 사용하여 다시 분석할 수 있다.
- 기존 자기 모델 progress.json에서 STORED 또는 EXPORTED_PENDING_UPLOAD 사건은 중복 분석하지 않는다. 저장 상태와 합의 반영 상태(HOLD 등)는 별개. 통합 승인하지 않는다.
- 다음 미완료 사건 ROOT-005 (250314SH2)부터 중립 큐 순서대로 수행. 원본 후보를 검증하며 파일명만으로 판본 확정 금지. 공통 문서가 이미 제공되면 재요청하지 않는다. 독립검토표 40행은 표준 JSON으로 생성.
- PDF 바이너리를 실제 다운로드할 수 없으나 해당 사건 원문 텍스트와 식별정보를 확인한 경우, 가능한 범위에서 분석 및 반환하되 sha256=null, PDF_READ_HASH_UNAVAILABLE, pdf_page_count=null(미확인 시), 미확인 pdf_pages=[]로 기록. 해시/물리 페이지 검증을 꾸며내지 않는다. 판본 불일치나 본문 부족은 BLOCKED_SOURCE. 해당 사건을 건너뛰고 다음 가능한 사건 시도.
- GitHub 직접 쓰기 실패 시 반복 시도하지 않고 사건별 4개 산출물과 progress.json을 ZIP으로 실제 반환. GitHub 등록은 통합 담당자가 수행. 저장 완료 확인을 기다리지 않고 다음 미완료 사건을 진행할 수 있다.
- 매 사건의 완료 기준: report.md, review.json, excel_import.csv, validation.md. 40코드·근거·참조·JSON/CSV 정합성 검사. 미실행 검사는 NOT_EXECUTED. 원본 보고서의 세부 설비 조작·안전기능 우회 재현 금지.
- 다른 AI 결과와 baseline/ 및 통합 Excel 열람 금지. 자신의 작업 폴더만 조회. 독립성 노출 기록은 삭제하거나 숨기지 않는다. approved=false, can_ship=false.
- 사용자 '다음' 명령 시 사건번호를 재요청하지 않고 자기 모델 진행 기록과 중립 큐에서 자동 결정하여 실제 수행. 처리 한도 내 사건별 완결, 다음 대상 기록. 백그라운드 작업 주장 금지.

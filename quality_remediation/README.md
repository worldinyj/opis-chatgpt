## 보완 정책
1. 원본 v1 및 INTAKE_STATUS, progress.json은 수정 금지. 매니페스트에 원본 blob, 기존 기록 SHA-256, 큐 판본 기대값 고정.
2. B02 원본 동결 재검증 및 입력 계약 확정. B03 독립 검증기 개발(엄격 CSV 파싱, 스키마, 키/역할/사유/출처, 수식 주입, 회귀시험). 기존 scripts/verify_baseline.py는 읽기 전용 참조.
3. B04는 6건 우선으로 JSON의 사유 및 실제 기록된 section/printed_pages/pdf_pages/fact_ids를 정확히 직렬화한 파생 CSV와 변경 목록 생성. 원문에 없는 값 추정 금지. 빈 배열의 표준 문구 적용은 사실 ID 존재 여부와 함께 확인. ROOT-004 형식 개선도 원문 이슈 해소와 별개.
4. B05는 ROOT-004 원본 PDF의 바이너리 해시·물리쪽 수·인쇄쪽 맵 확인 및 DM3/미열람 붙임 검토. 자료 접근 실패면 HOLD 유지.
5. B06 독립 재검증: 원본 불변, 40개 역할/판단/사유/사실 불변, 출처 직렬화 정확성, 신규 결함 0. 보완본에 SHA-256과 source_ref 기록. B07 품질보고서. B08 사용자 검토 및 적격성 재평가 요청. 모든 보완 산출물은 quality_remediation/ 하위만 작성. Gemini 원본 작성자가 만든 수정본과 ChatGPT 파생 형식 보완본을 구분한다.

## 승인 게이트
형식 보완 PASS는 원문 사실 타당성 및 독립성 확인을 대체하지 않는다. 다른 AI 판단을 참조해 Gemini 판단을 맞추지 않는다. 원본/파생 버전 연결, 별도 검증 및 승인 이후만 통합 대상 선택 가능. 현재 7건 모두 HOLD, eligible_for_three_ai_consensus=false, approved=false, can_ship=false. main 병합 없음.

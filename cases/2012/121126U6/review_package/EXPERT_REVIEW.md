# 전문가 별도 검토 — PILOT-25

- WP3 문서화: F07–F08, F23 — 문서의 해당 단계 불완전성과 의미 이해의 한계.
- CL4 교육 훈련: F05, F07, F09, F22 — 부분 경험과 해당 교육 부족. 자격 부재를 단정하지 않는다.
- WP1 작업 관리: F03, F06, F09, F20–F23 — 동시 작업·일정 압박 및 종료 확인 관리.

- PA3 팀워크: F10–F13, F23 — 조직 간 및 운전조 간 확인 협력의 문제.

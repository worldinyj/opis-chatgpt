# 토론 및 실천 — PILOT-26

교육용 초안 · 전문가 미승인 · 실제 설비/절차 재현 없음.

## 질문
- Q01: 작업 완료 기록과 실제 품질확인의 차이를 어떤 증거로 확인하고 조치 효과를 어떻게 평가하는가? (L01)
- Q02: 업무상 불확실성 또는 운영상 부담이 있는 상황에서 안전 우선의 판단과 승인된 기준 준수를 어떻게 평가하는가? (L02)
- Q03: 훈련 환경이 실제 업무의 특성을 충분히 반영하는지 어떤 검증 기록과 운전경험 자료로 확인하는가? (L03)

## 가상 시나리오
- T01: 가상의 일반 제조업체에서 작업 완료 기록은 있으나 품질검토 근거가 충분하지 않다. 관리자는 일정 부담이 있는 상황에서 완료 판단의 근거를 검토한다. 5분: 완료의 증거와 안전 우선 판단 및 승인 근거를 토론한다.
- T02: 가상의 일반 제조시설에서 교육용 모형과 실제 업무 환경의 차이가 확인됐다. 교육 담당자는 차이를 검증하고 문서와 교육 내용을 개선할 필요를 검토한다. 5분: 차이의 기록, 검증 책임, 교육 개선과 효과 확인을 논의한다.

## 실천 및 확인 증거
- A01 INDIVIDUAL: 작업 완료 및 품질 확인 근거를 검토하고 미확인 사항을 기록한다. 확인: 업무 완료·품질검토 기록
- A02 INDIVIDUAL: 안전 관련 판단에서 적용한 승인 기준과 판단 근거를 기록한다. 확인: 판단·승인 기록
- A03 INDIVIDUAL: 교육 내용과 실제 업무의 불확실성 또는 차이를 공식 검토 대상으로 제기한다. 확인: 교육 개선·문제 제기 기록
- A04 TEAM: 작업 완료 근거 및 품질 확인 기록을 표본 평가한다. 확인: 품질검토 및 효과평가 기록
- A05 TEAM: 사례 검토에서 안전 우선 판단과 규정 준수 근거를 구분해 평가한다. 확인: 사례 검토·시정조치 기록
- A06 TEAM: 교육 환경 검증과 운전경험 반영, 교육 개선의 효과를 추적한다. 확인: 교육 검증·학습·효과평가 기록

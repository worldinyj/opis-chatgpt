# 한국어 나레이션 초안

[S01] 확인 기록만으로 충분할까요?

[S02] 한울육호기 출력운전 중 원자로가 자동정지했습니다.

[S03] 정비 중 다른 종류의 전자카드가 사용됐습니다.

[S04] 보관상자에 여러 종류의 표시가 있었습니다.

[S05] 식별과 보관 관리가 지침대로 이행되지 않았습니다.

[S06] 계획서에 모델 식별과 점검 기록이 누락됐습니다.

[S07] 같은 누락이 있는 이전 계획서를 참조했습니다.

[S08] 작업등급에 필요한 검토 활동이 미흡했습니다.

[S09] 관련 부서의 작업전회의는 실제로 수행됐습니다.

[S10] 정비 수행자의 자기진단 적용이 미흡했습니다.

[S11] 감독자의 사전점검과 확인도 부족했습니다.

[S12] 확인 시점과 확인 대상의 개선이 필요했습니다.

[S13] 과거 변경의 시공 오류가 확인됐습니다.

[S14] 표시와 실제 상태에 불일치가 있었습니다.

[S15] 정지 후 급수 대응에도 개선점이 확인됐습니다.

[S16] 이후 비상운전절차와 안정화는 적절했습니다.

[S17] 필요한 안전기능이 유지됐습니다.

[S18] 발행 당시 단기 세 건이 완료됐습니다.

[S19] 중기 다섯 건이 재가동 전 완료 예정이었습니다.

[S20] 장기 네 건의 개선계획이 제시됐습니다.

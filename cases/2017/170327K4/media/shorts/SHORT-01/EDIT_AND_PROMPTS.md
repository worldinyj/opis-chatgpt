# 편집 및 생성 지시 초안

한국어 나레이션, BGM 별도, 자막 후편집. 조사 사실은 추상 그래픽만 사용. 가상 장면은 실제 원전·설비·인물·조작 재현 금지. 참조 및 비용 승인 전 외부 제출 금지.

- S01: CONTROLLED_GRAPHIC / 통제형 교육 그래픽, 발견은 해결이 아니다, 추상 아이콘 및 근거 카드. 실제 설비·조작 재현 없음. / 자막 발견은 해결이 아니다 · 교육용 초안
- S02: CONTROLLED_GRAPHIC / 통제형 교육 그래픽, 조사 사실, 추상 아이콘 및 근거 카드. 실제 설비·조작 재현 없음. / 자막 조사 사실 · 공식 조사결과
- S03: CONTROLLED_GRAPHIC / 통제형 교육 그래픽, 해결의 근거, 추상 아이콘 및 근거 카드. 실제 설비·조작 재현 없음. / 자막 해결의 근거 · 교육용 초안
- S04: STILL_MOTION / 가상의 일반 제조시설 교육회의실, 3D 브릭 인물과 추상 기록 카드. 가상 효과 검토. 실제 설비·원전·인물·조작 재현 없음. / 자막 가상 효과 검토 · 가상 교육 상황
- S05: CONTROLLED_GRAPHIC / 통제형 교육 그래픽, 발견에서 해결로, 추상 아이콘 및 근거 카드. 실제 설비·조작 재현 없음. / 자막 발견에서 해결로 · 교육용 초안

# 한국어 나레이션 초안

실제 음성 미생성. 시간은 설계값, 실측 대기.

- S01 0–6초: 기술 검증과 문제 해결의 실효성을 살펴봅니다.
- S02 6–12초: 조사팀은 변경 과정의 기술평가 미흡을 확인했습니다.
- S03 12–18초: 확인된 이상징후의 후속조치가 미흡했습니다.
- S04 18–24초: 기존 조치의 점검에서 추가 보완사항이 도출됐습니다.
- S05 24–30초: 변경의 영향과 검증 근거를 체계적으로 검토합니다.
- S06 30–36초: 변경 검토 문서와 검증 기록의 완결성을 확인합니다.
- S07 36–42초: 가상 팀이 변경 검토서와 검증 기록을 대조합니다.
- S08 42–48초: 발견과 실질적 해결은 다릅니다.
- S09 48–54초: 조치의 책임, 기한, 효과 확인을 함께 관리합니다.
- S10 54–60초: 가상 팀이 열린 개선조치의 확인 근거를 검토합니다.
- S11 60–66초: 유사사례의 공통점과 차이를 구분합니다.
- S12 66–72초: 기존 조치의 이행과 실제 효과를 구분합니다.
- S13 72–78초: 기존 경험반영 실적과 보완 필요를 함께 검토합니다.
- S14 78–96초: 다섯 가지 후보 속성입니다. 공식 평가가 아닌 교육용 해석입니다.
- S15 96–102초: 가상 팀이 과거 개선의 적용 범위를 검토합니다.
- S16 102–108초: 가상 팀이 조치의 효과 확인 근거를 공유합니다.
- S17 108–114초: 변경 검증과 후속조치, 경험반영은 충분합니까?
- S18 114–120초: 변경은 검증하고, 발견은 해결로 이어갑시다.

# 전문가 별도 검토 — PILOT-24

핵심 6개, 추가 21개, 낮은 관련성/근거 부족 13개. 승인 0개. 사용자 별도 검토.

- LA5 변화 관리: F03–F06, F13–F14, F21 — 설계변경의 검토·검증 관리. 리더 개인의 행태는 확인되지 않았다.
- WP2 설계 여유도: F04, F08, F13–F14, F19 — 엄격한 변경 프로세스와 공통원인 위험 평가의 학습 근거. 실제 설계 여유도 수치 위반 판정 아님.
- WP3 문서화: F06, F13 — 공식 설계문서 오류와 검토에서의 미식별. 문서 관리체계 전반의 실패를 단정하지 않는다.
- WP1 작업 관리: F14–F15, F20 — 변경 기능을 검증계획에 반영하고 품질확인 근거를 확보하는 작업관리 학습.
- WP4 절차 준수: F15 — 품질보증계획서의 요구된 재검사·재시험 누락이라는 공식 지적. 직접원인과 분리.
- PI2 문제 평가: F09–F12, F19–F22 — 일부 미재현 상태에서 추가 분석·다른 원인 점검을 검토한 조사 근거. 조사팀 평가와 불확실성의 구분.

쟁점: LA5/WP2 변경관리와 설계여유도 직접 위반 여부 구분, WP3 문서 오류와 관리체계 전반 구분, WP1/WP4 시험 범위 및 품질보증 요건 누락 분리, PI2 미재현과 추가 분석의 증거 강도 구분. PI4 반복 신호는 경향 분석 부재의 확정 근거가 아니다. CL1은 이미 진행된 조치와 후속 효과평가를 구분한다. 승인·제외·추가근거 및 사유를 별도 검토에서 기록.

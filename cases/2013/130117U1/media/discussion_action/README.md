# 토론 및 실천 — PILOT-24

교육용 초안 · 전문가 미승인 · 실제 설비/절차 재현 없음.

## 질문
- Q01: 변경된 문서의 정확성과 검토 근거를 누가 확인하며, 같은 변경이 여러 품목에 적용되는 경우 어떤 관리 증거가 필요한가? (L01)
- Q02: 기존 시험과 변경된 기능의 검증을 어떻게 구분하며, 공급사와 운영자의 품질보증 책임을 어떤 기록으로 확인하는가? (L02)
- Q03: 일부 현상이 재현되지 않는 경우 확인된 사실, 분석적 설명, 남은 불확실성을 어떻게 기록하고 검토하는가? (L03)

## 가상 시나리오
- T01: 가상의 일반 제조시설에서 공급사가 변경된 문서와 제품을 전달했다. 기존 시험 기록은 있지만 변경사항의 검증 근거가 명확하지 않다. 문서 검토와 인수 확인 책임을 토론한다. 5분: 변경 검토, 품질요건 확인 및 종료 근거의 책임을 정한다.
- T02: 가상의 일반 제조시설에서 조사 중 일부 현상은 재현됐지만 다른 현상은 재현되지 않았다. 팀은 사실과 추정, 추가 근거의 필요성을 구분한다. 5분: 확인된 근거와 남은 불확실성, 후속 평가 책임을 기록한다.

## 실천 및 확인 증거
- A01 INDIVIDUAL: 변경된 문서의 검토·승인 근거와 적용 범위 확인 기록을 요청한다. 확인: 변경 검토·승인 기록
- A02 INDIVIDUAL: 변경된 기능과 승인된 품질요건의 검증 근거를 질문한다. 확인: 검증 계획·승인 기록
- A03 INDIVIDUAL: 확인 사실과 추정, 미확인 사항을 구분해 공식 검토 기록에 남긴다. 확인: 문제평가 기록
- A04 TEAM: 변경 문서 및 적용 대상의 검토·승인 추적성을 표본 점검한다. 확인: 변경관리·문서 검토 기록
- A05 TEAM: 공급사 검증과 운영자 품질확인 기록의 충족 근거를 표본 평가한다. 확인: 품질보증·검증 기록
- A06 TEAM: 원인평가와 미확인 사항의 후속 검토 및 조치 효과를 추적한다. 확인: 원인평가·시정조치 기록

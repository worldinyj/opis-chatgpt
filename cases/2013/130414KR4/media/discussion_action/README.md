# 토론 및 실천 — PILOT-23

교육용 초안 · 전문가 미승인 · 실제 설비/절차 재현 없음.

## 질문
- Q01: 작업 종료 확인에서 발견 물체의 유입원과 관련 미회수 문제를 어떻게 평가하고 추적하며, 누가 완료 근거를 검토하는가? (L01)
- Q02: 교육에서 습득한 역량이 실제 업무에 전이됐음을 어떻게 확인하고 업무 중복 및 감독 책임을 어떻게 평가하는가? (L02)
- Q03: 예상하지 못한 상황에서 신속한 대응과 승인된 절차·정확한 진단을 모두 확보할 수 있는지 무엇으로 확인하는가? (L03)

## 가상 시나리오
- T01: 가상의 일반 제조시설 정비 종료 후 작은 물품 하나가 발견됐지만 유입원과 관련 물품의 회수 여부가 불명확하다. 원인 평가 및 후속 확인 증거를 논의한다. 5분: 완료 근거와 미해결 사항의 추적 책임, 위험성 평가 기록을 정한다.
- T02: 가상의 일반 제조시설에서 신규 업무를 맡은 팀원이 여러 업무를 동시에 수행하고, 예상하지 못한 상황에 팀이 대응한다. 역할·감독·승인된 절차의 확인을 논의한다. 5분: 역량 확인, 업무 조율, 절차와 판단의 검증 증거를 논의한다.

## 실천 및 확인 증거
- A01 INDIVIDUAL: 작업 종료 시 잔류 문제와 미해결 사항의 확인 기록을 요청한다. 확인: 작업 종료·문제평가 기록
- A02 INDIVIDUAL: 교육 이후 실무 수행 역량과 역할 확인에 필요한 질문을 기록한다. 확인: 교육 평가·역할 확인 기록
- A03 INDIVIDUAL: 예상하지 못한 상황에서 승인 절차와 진단 근거를 공식적으로 확인한다. 확인: 절차 검토·상황 기록
- A04 TEAM: 정비 종료 확인과 관련 미해결 문제 추적성을 표본 점검한다. 확인: 작업관리·시정조치 기록
- A05 TEAM: 교육 효과와 업무 중복, 협업 및 감독 책임의 이행 근거를 평가한다. 확인: 역량 평가·팀 검토 기록
- A06 TEAM: 비상상황 대응 훈련의 절차 준수·진단·팀 검증 증거를 평가한다. 확인: 훈련 평가·절차 검토 기록

# 토론 교안

Q01 일상적 정비로 보이는 작업의 특수 조건과 동시작업 영향을 어떻게 확인하는가?

Q02 설비 복구 후 실제 요구기능이 수행되었는지 어떻게 공동 확인하는가?

Q03 자발 보고자 보호와 정확한 운전기록을 어떻게 함께 지키는가?

T01 가상 산업시설에서 익숙한 작업과 다른 설비 특성이 확인되고 다른 시험이 예정되어 있다.
5분: 개인1·팀2·공유2분. 작업 특수성, 동시작업 영향, 승인 근거와 검토 책임을 토론. 실제 조작 모의 없음.

T02 가상 업무에서 오류를 자발 보고했고 설비는 복구됐지만 중요 경보 및 일지 기록이 불완전하다.
5분: 개인1·팀2·공유2분. 확인 사실, 미확인 기능, 객관적 기록과 공정한 보호를 논의.

A01 작업 특수 조건과 승인 절차를 확인한다. / 작업 전 확인 기록
A02 복구 후 미확인 기능 및 중요 경보의 검토를 요청한다. / 확인 요청·회신 기록
A03 오류를 보고하고 사실·조치를 기록한다. / 운전기록과 인계 근거
A04 동시작업 위험·작업전회의 범위·교육의 적절성을 표본 검토한다. / 영향 검토 및 교육 증빙
A05 사후 상황평가·시험 유효성·보고 판단 근거를 독립 검토한다. / 평가 및 판단 기록
A06 보고자 보호와 기록 완전성을 동시에 확인한다. / 기록 시정·후속 확인 및 보호정책

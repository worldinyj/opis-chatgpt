# 전문가 별도 검토 — PILOT-22

핵심 5개, 추가 22개, 낮은 관련성/근거 부족 13개. 승인 0개. 사용자 별도 검토.

- LA5 변화 관리: F06–F08, F19 — 변경 승인 후 추가 변경의 전파 및 반영체계 미비. 리더 개인의 행태는 추가 근거 필요.
- WP2 설계 여유도: F03–F08, F19 — 설계·변경 검증과 적용성 확인의 중요성. 실제 설계 여유도 위반을 확정하지 않는다.
- CO3 투명한 정보 공유: F07–F08 — 공급사 미통보와 조직 간 변경정보 전파 절차 미비. 의도적 은폐나 정보 공유 문화 전반의 실패는 미확인.
- WP1 작업 관리: F05, F09–F11, F18 — 중요시험 분류, 작업전회의 위험성 검토, 시험계획 및 상태 확인 범위의 문제. 개인 미준수로 단정하지 않는다.
- WP3 문서화: F11–F13, F18 — 절차의 확인 단계와 경보 설명·실제 정보 간 차이. 문서 체계 전체의 문제로 확대하지 않는다.

판정 쟁점: 공급사 미통보와 사업자 전파 절차 미비를 구분한다. LA5는 리더 개인의 행태 증거, WP2는 설계·변경관리 적합성, CO3는 실제 정보 전달 책임과 기록을 확인한다. WP1과 WP3는 시험계획·절차 자체의 문제와 실제 준수 행위를 분리한다. CL1은 시공 중 개선 경험과 운전경험의 관련성을 별도 확인한다. 긍정적 운전원 대응과 단기조치 완료를 보존한다. 승인·제외·추가근거 및 사유를 별도 검토에서 기록한다.

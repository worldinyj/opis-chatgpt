# 토론·실천 교육 초안

교육용 해석, 실제 사건 재현 아님. 전문가 승인 및 배포 금지.

## 토론 3문항
- Q01 최초 원인가설을 검증할 때 어떤 증거와 반증이 필요한가? 유사 경험은 어떻게 활용하는가? (L01)
- Q02 보수 완료와 재발방지 효과 확인을 어떻게 분리하고 후속 검사계획의 적정성을 평가하는가? (L02)
- Q03 문서상 설계 적합성과 실제 현장 적합성을 어떻게 구분하고 확인 책임을 연결하는가? (L03)

## 가상 시나리오 2개
- T01 가상의 일반 제조시설에서 품질 이상이 보수 후 다시 발견된다. 이전 원인평가와 유사 설비 기록을 재검토한다. 5분: 가설과 반증, 조치 효과의 판단 증거를 각각 제시한다.
- T02 가상의 일반 제조시설에서 문서 승인과 현장 상태 확인 결과가 일치하지 않는다. 5분: 공식 확인·보고, 기록 및 후속 검증의 책임과 증거를 토론한다.

## 실천과제 6개
- A01 INDIVIDUAL: 원인 검토 시 대안 가설과 반증 자료를 기록한다. 확인: 검토 기록
- A02 INDIVIDUAL: 조치 완료 증거와 효과 확인 증거를 따로 확인한다. 확인: 조치·효과 확인 기록
- A03 INDIVIDUAL: 문서와 현장 상태 차이를 공식적으로 보고한다. 확인: 공식 확인 및 보고 기록
- A04 TEAM: 선행·유사 사건의 적용성과 원인검토 범위를 표본 점검한다. 확인: 운전경험·원인평가 기록
- A05 TEAM: 후속 검사·효과 확인 계획의 위험 적합성을 표본 평가한다. 확인: 조치 효과 및 검사계획 검토 기록
- A06 TEAM: 현장 적합성 확인과 시정조치 후 검증 증거를 추적한다. 확인: 현장 확인·종결 근거

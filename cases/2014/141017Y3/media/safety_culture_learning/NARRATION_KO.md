# 한국어 나레이션 초안

출처: KINS 2014-16호(2015-03-20), 사건 141017Y3. 원본 텍스트층 일부 누락, 세부 수치 전수 대조 미수행.

실제 음성 미생성. 시간은 설계값, 실측 대기.

- S01 0–6초: 작업관리, 변경 검증, 정보공유와 평가를 살펴봅니다.
- S02 6–12초: 전문기관은 이물질에 의한 마모를 누설 원인으로 평가했습니다.
- S03 12–18초: 제작사 권고와 다른 절차 변경에 오류가 확인됐습니다.
- S04 18–24초: 조사팀은 소외 영향의 보수적 재평가를 요구했습니다.
- S05 24–30초: 작업관리와 예방정비의 실제 효과를 검토합니다.
- S06 30–36초: 확인된 원인과 추정된 원인을 구분합니다.
- S07 36–42초: 가상 팀이 작업관리 검토 기록을 확인합니다.
- S08 42–48초: 기술정보의 의미와 승인 근거를 확인합니다.
- S09 48–54초: 절차 변경은 적합성 검증으로 이어져야 합니다.
- S10 54–60초: 가상 팀이 변경 검토 기록을 확인합니다.
- S11 60–66초: 이상정보는 승인된 소통체계에 따라 공유합니다.
- S12 66–72초: 평가범위와 불확실성을 함께 검토합니다.
- S13 72–78초: 최초 평가와 보수적 재평가를 구분합니다.
- S14 78–96초: 작업 관리, 문서화, 변화 관리, 업무 소통, 보수적 성향, 문제 평가. 여섯 후보는 공식 판정이 아닙니다.
- S15 96–102초: 가상 팀이 서로 다른 품질정보를 검토합니다.
- S16 102–108초: 가상 팀이 개선과 검증 기록을 공유합니다.
- S17 108–114초: 확인 결과의 근거와 충분성을 검토하고 있습니까?
- S18 114–120초: 안전은 확인을 넘어 검증에서 완성됩니다.

# PPT-D 첫 사건 비교검증 결과

원본 샘플(사용자 제공, 제작 서비스 미확인)과 ChatGPT 로컬 전문형 R1을 실제 파일 기준으로 비교했다. 이전 PPT-B/C에서 실제 생성한 LibreOffice PDF를 로컬에서 재사용하여 이번 검사에 연결했고, 기존 16쪽 렌더링 모음도 다시 눈으로 비교했다. 신규 외부 서비스 호출 또는 PPT 재생성은 하지 않았다.

| 지표 | 선택 샘플 | ChatGPT 전문형 R1 |
|---|---:|---:|
| 장표 | 16 | 16 |
| 노트 있는 장표 | 0 | 16 |
| 전체 객체(배경/그림 포함) | 1081 | 388 |
| 상위 도형 경계 후보 | 11 | 0 |
| PDF 텍스트 대조 경고 | 2 (16쪽) | 0 |
| 동일 R1 본문 계약 누락 | 미적용 | 0 |
| 동일 R1 노트 계약 불일치 | 미적용 | 0 |

R1 원고 계약은 제작 명세의 제목 및 표시되는 카드 제목/본문과 노트 일치 검사. P01에 표시하지 않는 카드 라벨은 제외. 사실의 의미 정확성과 실제 독립 검토를 대체하지 않는다. 샘플은 내용 정답이 아니므로 R1 동일문구 계약을 적용하지 않았다. PDF 경고 수는 실제 손실의 확정 수치가 아니다. 원본 샘플 하단 텍스트 이탈/누락 후보 확인. 두 파일은 동일 16:9. 직접 지정 RGB Jaccard는 0.100~0.412(16개 매핑)이며 전문적 디자인 점수가 아니다. 글꼴 차이: 샘플 Noto Sans KR/Arial, R1 Noto Sans CJK KR. R1는 사진과 아이콘을 미복제해 샘플 대비 정보밀도와 시각적 다양성이 낮은 일부 장표가 있다. 실제 투사 및 사용자 디자인 만족도 미평가.

## 결론
R1의 발표자 노트와 원칙별 미진속성 종합, 원인 분류·사실 표현 및 경계 검사 결과를 유지한다. 샘플의 사진/아이콘 기반 표지, 풍부한 사건 흐름과 2열·3열 시각 구조, 수치 카드는 향후 재구성할 가치가 있다. 디자인 유사도와 교육 효과를 단일 수치로 순위화하지 않는다. 9개 재사용 후보는 검토 대기, 승인 0. 실제 외부 전문 AI 산출물·도구별 비용/시간·실제 교육 효과 미평가. can_ship=false.

## 실행 증빙
로컬 Python 실행: 10/10 단위 테스트 통과(아카이브/노트, 결손 내용, 계약 장수, ZIP 경로, 임베디드 객체, 외부 관계, DTD, 빈 임베딩 디렉터리, 매핑 해시/범위, 잘못된 PDF 장수). 초기 수입에서 빈 ppt/embeddings/ 디렉터리를 실제 임베디드 객체로 오인하여 수정 후 실제 두 파일 검사 및 10개 테스트 재실행. 로컬 파일 및 GitHub blob 코드·테스트 해시 일치. 실제 PDF 대조는 기존 렌더링 PDF 재사용, 이 실행에서 새 렌더링하지 않음. 전체 로컬 감사 JSON에는 추출 원문이 포함될 수 있어 공개 저장소에는 수치/관찰 요약만 등록. 실제 파일 해시와 비교 데이터는 COMPARISON_PPTD.json에 기록. 유료 호출·외부 전송 0.

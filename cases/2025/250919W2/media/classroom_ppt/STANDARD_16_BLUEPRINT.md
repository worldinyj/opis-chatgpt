# 첫 사건 표준형 PPT — 16장 설계 초안

기존 R3 12장과 별개. 52분 제안(진행자 노트 포함). 사용자 샘플 등록 및 16개 자체 레이아웃 매핑 완료; 실제 PPTX 미생성. 전문가 검토 대기. 원본 사실과 AI 교육 해석 구분. 

## P01 표지 (2분)
**월성2호기 감속재정화계통 중수 누설 사건 안전문화 분석**
- 원전 종사자 교육용 사례 분석
- 익숙함이 안전을 보장하지 않는다

- 시각/레이아웃: 표지 스타일 우선; 샘플 매핑표 참조.
- 근거: 교육 구성
- 발표자 노트: 분석 v0.1.1, KINS 2025-07호, 교육용 초안. 실제 사건명을 표시하는 공개보고서 교육 모드; 비난이 아닌 학습. 현장 절차 대체 아님.

## P02 교육 목표 (2분)
**사건에서 현장 행동으로**
- 사건·원인을 이해한다
- 원칙별 교훈을 설명한다
- 개인과 팀의 실천을 제안한다

- 시각/레이아웃: 목차/학습목표 레이아웃; 샘플 매핑표 참조.
- 근거: L01, L02, L03
- 발표자 노트: 한수원 10원칙·40속성 표준 1.0 적용. 종료 시 참여자가 세 행동을 설명하도록 한다.

## P03 사건 개요 (3분)
**계획예방정비 중 중수 누설 보고**
- 2025.09.19 · 월성2호기
- 운전모드 5(보증정지), 출력 0%
- 시설 내부 중수 누설 보고대상

- 시각/레이아웃: 정보 카드/표; 샘플 매핑표 참조.
- 근거: F01, F10, F11
- 발표자 노트: 원본 pp.3–5. 최초 인지·현장 확인·보고대상 확인 구분. 보고서 표기 발생일과 인지일을 동일 개념으로 단정하지 않는다.

## P04 사건 흐름 (3분)
**이상 발견과 후속 확인은 구별된다**
- 9.18 작업 준비·초기 이상 및 작업 중단
- 9.19 누설 확인·보고 및 대응
- 9.21 복구 및 누설 차단

- 시각/레이아웃: 가로 타임라인; 샘플 매핑표 참조.
- 근거: F01, F03, F06, F10, F12
- 발표자 노트: 원본 pp.3–5, 8–10, 17–18. 사전검토회의는 별도 시점. 원본 승인 일자 차이는 미해결로 표시; 세부 작업 순서나 방법을 재현하지 않는다.

## P05 계통 및 작업 개념 (3분)
**밀봉과 작업조건의 확인이 중요하다**
- 감속재정화계통: 감속재 품질 유지
- 필터: 정화 기능, 밀봉: 누설 방지
- 작업조건의 적절한 확인 필요

- 시각/레이아웃: 기능 개념도; 샘플 매핑표 참조.
- 근거: F02, F06
- 발표자 노트: 보고서 §6.1 및 원본 pp.9–12. 실제 계통도·조작 지침이 아닌 기능 중심 개념도. 보고서의 기술 설명을 강사가 보완한다.

## P06 직접원인 (3분)
**밀봉 오링 손상으로 밀봉 기능 상실**
- D1 물리적 직접원인
- 조건 확인 미흡은 발생 배경
- 비상조치 미이행은 지속 관련 관리 원인

- 시각/레이아웃: 원인-결과 도형; 샘플 매핑표 참조.
- 근거: F02, F03, F06
- 발표자 노트: 원본 §3.2.1 및 §4, 보고서 §2.1–2.4. D1/R3 혼합 금지. 조사팀이 운영자 분석을 타당하다고 판단했다.

## P07 근본원인 (3분)
**관리 과정의 방어 요소가 충분히 작동하지 않았다**
- R1 변경·승인 관리 / R2 확인·판단 근거
- R3 이상 대응·재평가
- R4 시정조치·운전경험

- 시각/레이아웃: 4분면 원인 카드; 샘플 매핑표 참조.
- 근거: F02, F03, F04
- 발표자 노트: 보고서 §2.2 교육용 재분류. KINS 공식 근본원인 코드 아님. 설비 형상관리 단계 자체의 미흡을 별도 근본원인으로 확정하지 않는다.

## P08 기여원인 (3분)
**발생과 인지 지연을 구분하자**
- C1 기존 설비 열화·내부누설
- C2 감시설비 설계·현장 불일치
- 확인방법 한계는 R2, 운전경험은 R4

- 시각/레이아웃: 두 원인 경로 비교; 샘플 매핑표 참조.
- 근거: F02, F04, F07
- 발표자 노트: 원본 pp.10–16, 16–18, 보고서 §2.3. C1은 기술적 기여 조건, C2는 인지 지연. 어느 하나가 전체 사건을 반드시 예방했을 것이라고 단정하지 않는다.

## P09 작업관리와 의문제기 (3분)
**변경되면 다시 확인하고 재검토한다**
- WP 작업 프로세스
- QA 의문 제기
- 불확실성은 공식 절차로 다룬다

- 시각/레이아웃: 원칙 카드+행동; 샘플 매핑표 참조.
- 근거: F02, F03, F12, L01, L02
- 발표자 노트: PA는 추가 검토 후보의 맥락이지 핵심 미진원칙 확정이 아님. 실제 중단 행동 인정, 후속 재평가 강조. L01/L02의 다른 원칙과 연결하되 화면에서는 WP·QA 초점.

## P10 의사소통과 의사결정 (3분)
**공통 이해와 판단 근거를 확인한다**
- CO 안전중심 의사소통
- DM 의사결정
- 변경 승인·공유·보수적 판단

- 시각/레이아웃: 원칙 카드+행동; 샘플 매핑표 참조.
- 근거: F02, F03, L01, L02
- 발표자 노트: LA는 리더의 구체적 실행 증거 부족으로 추가 후보. 강사는 작업자에게 해결 부담을 전가하지 않는 관리자 역할을 토론한다.

## P11 학습과 문제해결 (3분)
**반복 문제를 개선과 학습으로 연결한다**
- PI 문제 파악 및 해결
- CL 지속적 학습
- CAP·운전경험·효과 확인

- 시각/레이아웃: 개선 순환 개념도; 샘플 매핑표 참조.
- 근거: F04, L03
- 발표자 노트: 원본 §3.2.4. PI1은 CAP 연결 미이행 사례로 한정. 경향분석 PI4는 추가 후보, 예방정비 연계는 교육 제안. 반복 문제가 곧 개인의 안전의식 결함은 아니다.

## P12 미진속성 종합 (3분)
**6개 관련 원칙 · 12개 핵심 후보**
- WP1 작업 관리 · WP3 문서화 · WP4 절차 준수
- CO1 업무 소통
- QA2 불확실성 확인 · QA4 자만 방지
- DM1 일관적 프로세스 · DM2 보수적 성향
- PI1 문제 파악 · PI2 문제 평가 · PI3 문제 해결
- CL1 운전 경험

- 시각/레이아웃: 6그룹 카드/표 한 장; 샘플 매핑표 참조.
- 근거: L01, L02, L03
- 발표자 노트: 분석 v0.1.1 §3.4·3.6. 공식 평가 아님, 미선정은 양호 아님. QA4 별도 후보 유지 여부와 PI1 범위 전문가 검토 대기. 추가 후보 12개는 보고서 참조.

## P13 방사선 영향 및 안전성 (3분)
**결과 평가와 관리 교훈은 별개다**
- 총 누설 1,311.15 kg-D2O
- 작업자 최대 3.63 mSv · 주민 예상 1.78×10⁻⁴ mSv/yr
- 보증정지 유지 · INES 기초 0, 최종 미확인

- 시각/레이아웃: 수치 카드/구분 표; 샘플 매핑표 참조.
- 근거: F08, F11, F12
- 발표자 노트: 원본 pp.18–21. 총 평가량에는 회수 1,306.01 및 외부 배출 5.14 kg-D2O 포함. 두 선량 직접 비교 금지. 삼중수소 전체 측정량 1.82×10¹² Bq와 사건 기여 평가 1.52×10¹² Bq를 구분(원본 p.20 직접 대조; F08 보강 후보 F13, 승인 전).

## P14 재발방지대책 (3분)
**완료와 예정, 효과 확인을 구분한다**
- 발행 당시 단기조치 완료
- 발행 당시 중장기조치 예정
- 현재 이행 여부 미확인

- 시각/레이아웃: 2트랙 로드맵; 샘플 매핑표 참조.
- 근거: F09, F12
- 발표자 노트: 원본 pp.21–23. 단기 7건, 중장기 8건. 예방정비, CAP 자체진단, 작업관리 교육 등. 실제 후속 이행을 최신 자료 없이 단정하지 않는다.

## P15 토론 및 실천 (10분)
**우리 업무에서 무엇을 확인할 것인가?**
- 조건 변경 시 재검토와 공유는?
- 관찰과 확인 대상은 일치하는가?
- 반복 이상을 CAP로 연결하는가?

- 시각/레이아웃: 질문+체크리스트; 샘플 매핑표 참조.
- 근거: L01, L02, L03
- 발표자 노트: Q01–Q03, 가상 T01/T02 각 5분 축약형. 개인 A01/A03/A04 및 팀 A02/A05/A06을 연결한다. 팀의 확인 기준·기간·분모·책임 설정은 후속 실천으로 기록. 구체 설비 조작을 모의하지 않는다.

## P16 마무리 (2분)
**작은 불확실성을 공식적으로 다루자**
- 변경 시 재검토 · 근거 확인 · 반복 문제 학습
- KINS 2025-07호 / 분석 v0.1.1
- 교육용 초안 · 전문가 승인 전

- 시각/레이아웃: 마무리 레이아웃; 샘플 매핑표 참조.
- 근거: L01, L02, L03
- 발표자 노트: 핵심 3행동을 다시 확인하고 참석자가 한 가지 실천을 선택한다. 승인 전 공식 교육 배포 금지.

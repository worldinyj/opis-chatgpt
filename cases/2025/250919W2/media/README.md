# 첫 사건 멀티미디어 교육 콘텐츠 적용안 V1.0

사건 ID 250919W2 / 원본 KINS 2025-07호(2026-03-23) / [분석보고서 v0.1.0](../report.md) / [메타데이터](../metadata.yaml) / [출처](../source.md). 분석 상태 DRAFT, 본 적용안 PLANNED. 독립 검토 및 전문가 승인 전 확정하지 않는다.

## 1. 공통 교육 목적
작업조건 변경 시 계획·판단 근거를 재검토하고, 반복되는 문제를 공식 개선체계와 운전경험 학습에 연결하는 행동을 학습한다. 안전문화 6개 관련 원칙과 12개 핵심 후보는 분석 초안의 결과이며 원칙별 조직 수준의 평가가 아니다. 공식 사실과 AI 해석 및 가상의 대안 행동을 구분한다.

## 2. 원칙 중심 학습 주제
| 주제 | 관련 원칙(표시 명칭) | 행동 |
|---|---|---|
| 변경된 조건, 변경되어야 할 계획 | WP 작업 프로세스, CO 안전중심 의사소통 | 변경을 승인 문서와 공동 이해에 연결 |
| 판단하기 전에 확인하라 | QA 의문 제기, DM 의사결정 | 불확실성을 확인하고 판단 근거를 검토 |
| 반복 문제는 학습의 신호 | PI 문제 파악 및 해결, CL 지속적 학습 | 문제를 공식 등록·평가·해결하고 운전경험을 적용 |

원칙의 표시 명칭은 교육용 축약. 공식 문구는 [표준](../../../../standards/safety_culture_40.md) 참조. 본문에서는 위 6개 원칙 및 세 주제를 중심으로 설명한다.

## 5. 사건 이해 영상 — 120~150초 제안
KINS 원본 중심: 사건 배경과 계획정비 상황 → 누설 확인과 조사 결과 → 관리 및 기술적 원인 개요 → 영향 평가와 대응 → 공식 재발방지대책(보고서 시점 완료/예정 구분) → 교훈/출처. 분석보고서의 원칙별 해석을 사실로 혼합하지 않음. 원본 §1–4 및 붙임의 참조 ID를 지정하고 세부 경위는 원문을 참조하도록 안내. V02 원칙에 따라 개별 I2V/정지 이미지/통제형 편집 혼합; 화면 발전소명 익명화 기본.

# 통제형 편집 계획 R2

- 120초, 1280×720, 24fps, 하드컷, overlap=0. 9:16은 필요 시 별도 재프레이밍/검수. 배경색 연회색·청회색, 높은 대비, 하단 자막 영역 확보.
- 모든 화면 글자·출처·수치·원칙 코드는 후반 삽입. 생성 영상에 글자를 넣지 않는다. 사실/해석/가상 표시를 구간 내 유지. 실제 인물·배치·절차 재현 없음.
- 음성은 구간별 WAV, BGM 별도(사용권 확인 후), 원본 영상 소리는 사용하지 않음. 현재 도구의 BGM/자동 자막 및 실제 겹침 전환은 미구현.
- S14 속성 종합 화면 18초 유지. attribute_summary.json의 6개 원칙·12개 후보를 한 페이지에 표시하며 AI 교육용 초안 표시를 유지.
- 사건 명칭은 출처 원장에 보존; 교육 화면은 익명화 기본. 숫자와 표기 원본 대조 필요. 실제 자산과 음성 미생성.

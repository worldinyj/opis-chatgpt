# MEDIA-008-J~K — 전달력 및 스토리텔링 개선안

## 대상별 학습 확인
| 대상 | 핵심 질문 | 교육 후 확인 |
|---|---|---|
| 운전 | 판단에 사용한 관찰이 확인 목적과 일치하는가 | 확인된 사실과 가정을 분리하고 재검토 요청 경로 설명 |
| 정비 | 현장 조건 변경이 승인본·작업전회의와 연결되는가 | 변경 공유 및 확인 근거를 자신의 업무에 적용 |
| 엔지니어링 | 판단 기준, 반복 이상과 운전경험을 어떻게 검토하는가 | 공식 검토 및 후속조치 효과 확인 방법 설명 |
| 관리자 | 불확실성 제기를 지원하고 후속조치 책임을 부여하는가 | 책임·기한·확인 방법을 제시, 개인에게 해결 부담 전가 금지 |

평가: 교육 전후 같은 질문 3개를 사용해 근거/공통 이해/후속 확인을 구분하도록 한다. 제안 채점 0=미응답/일반론, 1=관련 행동, 2=근거와 담당/확인 방법 포함. 6점 만점은 학습 확인용으로 안전문화 등급이나 개인 인사평가가 아니다. 실제 참여자 평가 미실시.

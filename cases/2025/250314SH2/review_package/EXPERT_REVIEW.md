# 독립·전문가 검토용 쟁점

사용자가 월성2호기와 신한울2호기를 별도로 검토할 예정. 이번 작성자 검토는 승인 아님.

| 속성 | 근거 및 반론 | 전문가 판단 |
|---|---|---|
| WP1 작업 관리 | 연료결함 상태에서 정례 업무의 조건과 위험을 함께 검토하는 작업관리 필요. WP1은 작업 프로세스의 충분성에 한정한다. 승인절차 위반이라고 주장하지 않는다. | PENDING |
| WP3 문서화 | 시료채취 절차와 일시적 경고 평가 절차가 변화된 조건에 필요한 기준을 담지 못함. 문서의 내용 적정성이지 서명·개정 지연의 증거가 아니다. | PENDING |
| CO1 업무 소통 | 관련 계통 상태 미인지와 부서 간 협조 개선 필요가 직접 확인됨. 발전부의 선제적 통보 및 요청은 긍정 대응으로 병기. | PENDING |
| QA2 불확실성 확인 | 반복 경고 및 검출하한치 미만 결과의 불확실성을 해결하는 재평가 필요. 작업중단 여부는 원문에서 직접 입증되지 않아 핵심 유지 여부를 전문가가 판단. | PENDING |
| QA4 자만 방지 | 변화된 운전조건과 교번 업무의 잠재적 위험을 사전에 충분히 고려하지 못함. 심리적 자만의 증거 아님; QA2와 중복 가능. | PENDING |
| DM1 일관적 프로세스 | 선택 기준과 경고 평가 방법의 체계성을 보완할 필요. 당시 절차를 따른 판단과 절차 설계의 한계를 분리. | PENDING |
| DM2 보수적 성향 | 높아진 방사성물질 농도와 불확실한 시료 결과를 포함하는 신중한 평가 필요. 당시 이용 가능 정보와 대안 평가 근거는 제한적. | PENDING |
| PI2 문제 평가 | 실제 누출을 반복 신호와 함께 평가하고 원인을 식별·조치할 필요. 당시 발전부 원인 파악 지속, 사후 조사 및 대책을 인정. CAP 시스템 전체의 결함 아님. | PENDING |

원본·분석 v0.1.0·F/L 원장·영상/숏폼 명세·PPT를 동시에 확인. 후보 변동 시 모든 파생자료와 index 재생성. 전문가 성명/판본/판정/근거/날짜는 실제 검토 후 기록. 별도 승인 전 사용 금지.

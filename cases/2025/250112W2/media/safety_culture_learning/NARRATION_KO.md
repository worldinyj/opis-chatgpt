# 한국어 나레이션 초안

[S01] 익숙함이 확인을 대신할 수는 없습니다.

[S02] 실제 격리상태와 확인 결과가 일치하지 않았습니다.

[S03] 필수 절차 미사용과 운전편의 관행이 확인됐습니다.

[S04] 인지 후 보고와 조치는 적절하게 평가됐습니다.

[S05] 경험과 실제 확인 결과를 구분합니다.

[S06] 필수 절차를 사용하고 불확실성을 재검토합니다.

[S07] 가상의 팀은 확인 근거를 기록합니다.

[S08] 절차와 관행의 차이를 알았지만 문제제기는 없었습니다.

[S09] 현장 불편을 공식 개선 질문으로 바꿉니다.

[S10] 절차와 실제 업무의 차이를 공유합니다.

[S11] 감시 기능의 일부가 설계대로 구현되지 않았습니다.

[S12] 문서와 구현, 시험 근거를 함께 검토합니다.

[S13] 관련 변경정보의 적용 여부와 효과를 확인합니다.

[S14] 다섯 원칙의 열 개 후보입니다. 전문가 검토 전 교육용 해석입니다.

[S15] 차이와 불확실성을 기록하고 질의합니다.

[S16] 문서와 현장 확인 근거를 공동 검토합니다.

[S17] 우리 팀의 익숙한 관행은 확인되고 있습니까?

[S18] 익숙함 대신 확인, 관행 대신 개선입니다.

# 한국어 나레이션 초안

실제 음성 미생성. 길이는 설계값이며 음성 실측 검증 대기.

- S01 0–6초: 불확실할수록 검토의 근거가 중요합니다.
- S02 6–12초: 조사팀은 작업계획의 미흡을 확인했습니다.
- S03 12–18초: 판단 오류와 검증 부족이 지적됐습니다.
- S04 18–24초: 교대 때 필요한 회의가 재수행되지 않았습니다.
- S05 24–30초: 계획이 달라지면 위험도 다시 평가해야 합니다.
- S06 30–36초: 반론과 독립적 확인은 판단의 방어입니다.
- S07 36–42초: 가상의 팀이 기존 작업 범위를 다시 검토합니다.
- S08 42–48초: 교대는 책임과 미해결 문제의 전달입니다.
- S09 48–54초: 긴급 판단의 책임이 명확해야 합니다.
- S10 54–60초: 가상 팀이 확인할 근거를 기록합니다.
- S11 60–66초: 안전을 지원하는 자원과 근무환경이 필요합니다.
- S12 66–72초: 과거 교훈은 실제 업무변화로 이어져야 합니다.
- S13 72–78초: 행정적 종결과 개선의 효과는 다릅니다.
- S14 78–96초: 세 학습 메시지는 열여덟 개 후보 속성과 연결됩니다. 이는 전문가 검토 전의 교육용 분류입니다.
- S15 96–102초: 가상 팀이 과거 개선의 효과를 확인합니다.
- S16 102–108초: 가상 담당자가 근무 부담을 공식적으로 제기합니다.
- S17 108–114초: 우리 조직은 검토와 학습의 증거를 갖고 있습니까?
- S18 114–120초: 불확실성 확인, 책임 연결, 개선 효과 확인.

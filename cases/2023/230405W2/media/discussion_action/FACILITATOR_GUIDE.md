# 현장 토론 교안

Q01 관리대상 분류 또는 제외 기준이 바뀔 때 안전 영향과 승인 근거는 어떻게 확인하는가?

Q02 허가된 조건이 바뀌거나 일정이 연기되면 어떤 공식 검토와 정보 공유가 필요한가?

Q03 반복 작업의 경험이 실제 상태 확인을 대신하지 않도록 어떤 근거를 남기는가?

T01 가상 산업시설에서 여러 해 동안 고위험 작업관리 대상이 줄었다. 일부 제외 사유의 근거를 찾기 어렵다.
5분(개인1·팀2·공유2): 분류 근거, 승인, 영향 검토, 재검토 책임과 증빙을 논의한다.

T02 가상 업무의 일정과 조건이 바뀌었으나 이전 허가서만 남아 있고 작업자는 유사 업무 경험을 근거로 준비한다.
5분(개인1·팀2·공유2): 확인된 조건, 미확인 항목, 공식 재검토·인계 및 증빙을 논의한다. 실제 설비 조작 모의 없음.

A01 작업 분류 및 제외 근거를 승인 문서와 대조한다. / 분류 근거와 승인 기록
A02 일정·조건 변경을 공식 검토에 연결한다. / 변경 검토 및 인계 기록
A03 반복 경험과 무관하게 요구된 조건 확인 증빙을 남긴다. / 승인 절차에 따른 확인 기록
A04 분류 변경의 영향과 표준지침 일치 여부를 표본 검토한다. / 분류 변경 이력 및 기술검토 근거
A05 독립검토·위험평가·허가 및 착수 정보의 연결을 검증한다. / 단계별 검토 및 회신 기록
A06 작업전회의와 독립확인의 실제 효과를 검토한다. / 표본 확인·미비점·후속 조치

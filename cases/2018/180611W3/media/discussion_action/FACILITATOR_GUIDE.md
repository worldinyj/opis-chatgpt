# 토론 운영 초안

- 무엇이 확인되지 않았을 때 작업을 보류하고 어떻게 공식적으로 소통할 것인가?
- 확인 절차의 역할과 실제 교육 역량을 어떤 근거로 검증할 것인가?
- 교육 수료나 조치 종결이 실제 재발 방지로 이어졌는지 어떻게 평가할 것인가?

가상의 일반 산업시설에서 작업대상 문서와 현장 식별 정보가 불일치한다. 5분: 확인되지 않은 정보, 공식 검토, 역할 및 작업 범위를 논의한다.

가상의 일반 산업시설에서 이전 개선 교육을 완료했지만 유사한 문제가 다시 발견되었다. 5분: 수료와 역량, 종결과 효과, 적용 범위를 구분한다.

- 불확실한 사항을 공식 제기하고 확인 근거를 기록한다. 검증: 검토 기록
- 작업 전 역할과 확인 범위를 점검한다. 검증: 작업전회의 기록
- 과거 경험의 적용 가능성을 확인한다. 검증: 경험 검토 기록
- 확인 및 보고의 적정성을 표본 검토한다. 검증: 확인·소통 표본
- 교육과 훈련의 실제 역량을 평가한다. 검증: 관찰 및 평가 기록
- 개선조치의 효과성과 적용 범위를 재검토한다. 검증: 효과 평가 기록

전문가 미승인. 현행 승인 절차 우선.

# 한국어 나레이션 초안

실제 음성 미생성. 시간은 설계값, 실측 대기.

- S01 0–6초: 인적오류를 줄이는 조직의 방어를 살펴봅니다.
- S02 6–12초: 조사팀은 의문과 불확실시 중지의 미흡을 지적했습니다.
- S03 12–18초: 현장운전원 교육의 실습과 관찰이 부족했습니다.
- S04 18–24초: 기존 교육과 재발방지대책의 실효성에 한계가 있었습니다.
- S05 24–30초: 확인되지 않은 사실과 가정을 구분합니다.
- S06 30–36초: 불확실하면 업무를 보류하고 공식 확인을 요청합니다.
- S07 36–42초: 가상 팀이 문서와 현장 정보의 차이를 발견합니다.
- S08 42–48초: 작업 전에 확인 역할과 범위를 명확히 합니다.
- S09 48–54초: 교육 수료와 실제 업무 역량은 다릅니다.
- S10 54–60초: 가상 팀이 실습을 관찰하고 피드백을 나눕니다.
- S11 60–66초: 유사 경험의 적용 가능성을 검토합니다.
- S12 66–72초: 조치의 종결과 실제 효과를 구분합니다.
- S13 72–78초: 교육 제도의 존재와 실효성의 한계를 구분합니다.
- S14 78–96초: 여덟 가지 후보 속성입니다. 공식 평가가 아닌 교육용 해석입니다.
- S15 96–102초: 가상 팀이 이전 교육 후 남은 문제를 검토합니다.
- S16 102–108초: 가상 팀이 개선 효과의 확인 근거를 논의합니다.
- S17 108–114초: 확인, 실습, 효과성은 우리 업무에 어떻게 적용됩니까?
- S18 114–120초: 멈춤과 확인, 실습과 학습을 실천합시다.
